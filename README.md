# AI-Based Carbon Footprint Prediction and Sustainability Recommendation System 🌱

## Project Overview

This project calculates a user's annual carbon footprint based on:

- Transportation
- Flight travel
- Electricity consumption
- Food habits

The system also:
- Shows emission breakdown charts
- Predicts future emissions using Machine Learning
- Provides sustainability suggestions

---

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

---

## Features

- Carbon footprint calculation
- Pie chart visualization
- AI sustainability suggestions
- Future carbon prediction
- Dashboard interface
